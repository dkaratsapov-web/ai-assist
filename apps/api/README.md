# apps/api

Backend ADS OS: FastAPI, SQLAlchemy 2.0 (async), Alembic, PostgreSQL.

Pydantic-схемы здесь — источник правды для контракта API. OpenAPI генерируется
FastAPI, TypeScript-типы — в `packages/schemas` (v0.4 §18).

## Запуск

```bash
python3 -m venv .venv && .venv/bin/pip install -e "apps/api[dev]"   # из корня
pnpm api:migrate        # миграции
pnpm api:dev            # http://localhost:8000/docs
pnpm api:test           # тесты
```

Демонстрационные данные (v0.3 §76):

```bash
.venv/bin/python apps/api/scripts/seed_demo.py
```

Скрипт печатает идентификаторы организации и пользователя — их нужно положить в
`apps/web/.env.local`, пока не подключена настоящая аутентификация.

## Решения, которые стоит знать

**У репозитория нет способа получить незаполненный запрос.** Фильтр по
организации применяется слоем репозитория, а не вызывающим кодом: цена одной
забытой проверки — утечка данных чужого клиента. Доступ поверх границ арендатора
вынесен в отдельный класс `SystemRepository` с говорящим именем и записью в лог,
чтобы такой вызов было видно на ревью.

**Чужой объект даёт 404, а не 403.** Разница между «нет доступа» и «не
существует» позволила бы перебором выяснять, какие идентификаторы есть у других
организаций (SEC-001).

**Экономика различает три состояния каждой величины:** посчитано по данным
клиента, посчитано с нашим допущением, посчитать нельзя. Правдоподобное число на
месте третьего случая опаснее пробела — на него будут опираться при решениях о
деньгах (v0.4 §5).

**Провайдер AI не выбран.** Имя провайдера не встречается ни в одном модуле
бизнес-логики: работа идёт на детерминированной заглушке, реальный провайдер
подключается конфигурацией (v0.3 §98). Запрос с чувствительными данными
отклоняется, пока не разрешён политикой организации (v0.4 §2.3).

**Аутентификация ещё не подключена.** Контекст организации приходит заголовками
и только вне production — на боевом стенде такой запрос отклоняется. Полноценная
аутентификация с MFA (v0.3 §91) делается отдельным срезом.

## Тесты

```bash
pnpm api:test
```

Требуется PostgreSQL с базой `ads_os_test`: тесты изоляции арендаторов идут
против настоящей базы. Подменять её SQLite нельзя — проверяется поведение
запросов и ограничений, и различия диалектов сделали бы проверку декоративной.
